iTask Manager

Descrição: Projeto desenvolvido como parte do desafio técnico do Processo de Trainee da IJunior (UFMG).

O objetivo foi criar um gerenciador de tarefas inteligente, focado em produtividade e alta performance, permitindo o controle dinâmico de atividades através de uma interface intuitiva e interativa.

O foco principal do desafio foi a aplicação avançada de TypeScript e Programação Orientada a Objetos (POO), integrando funções para feedbacks visuais e sonoros, além da manipulação do DOM para uma barra de progresso em tempo real.

TypeScript HTML CSS UX/UI

Sistema de Prevenção de Incêndio

Descrição: Projeto Final desenvolvido para a disciplina de Introdução ao Projeto de Engenharia na UFMG.

O sistema utiliza um Arduino Uno integrado a um sensor de ondas infravermelhas (KY-026) para detecção de focos de calor.

O sistema inicia o processo de varredura e ao identificar a presença de chamas, coordena o acionamento de uma mini bomba d'água para a liberação de jatos direcionais.

Toda a lógica de movimentação, sincronização e ativação dos componentes foram implementadas em C/C++.

Arduino C C++

Plataforma de Gerenciamento e Controle de Estoque

Descrição: Projeto desenvolvido como parte do Desafio de Introdução (ENG200), com o objetivo de propor uma solução real para os problemas de controle de estoque da empresa Make More.

O sistema foca na otimização de fluxos logísticos e no monitoramento rigoroso de inventário, através de estruturas de dados implementadas em Python, oferecendo uma interface intuitiva para atualização e gerenciamento dos produtos em tempo real.

A solução foi desenhada para garantir a integridade das informações e facilitar a tomada de decisão estratégica em um cenário empresarial real.

Python Estrutura de Dados

Portifólio Pessoal
